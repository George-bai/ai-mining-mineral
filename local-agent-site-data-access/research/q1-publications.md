**A small, locally run language model can find industrial tags and retrieve readings. Choosing the right tag is the part that most needs testing.** An ABB historian prototype converted the requested time correctly in **30 of 30** test questions, but chose the correct variable identifiers in only **18 of 30**. A separate study ran a small model against a factory’s live time-series database. On eight time-sensitive aggregation questions, every generated query executed and **none returned the exact reference result**. [ABB historian thesis, Table 2](https://trepo.tuni.fi/bitstream/handle/10024/226285/KorpelaOssi.pdf?isAllowed=y&sequence=2) · [Factory study, Table 11](https://www.frontiersin.org/journals/artificial-intelligence/articles/10.3389/frai.2026.1764367/full)

**For mining, I found evidence of agents reading historical gas alarms and connected-machine telemetry, and an operator reporting a database assistant at a named concentrator.** In publications I could verify from January 2023 through **23 November 2026**, I found no producing mineral concentrator that documented all four together: a small model running on site, a query against identified mill historian tags, an enforced read-only connection, and independently checked answers. The closest local demonstrations used a SCADA test project and archived readings from an operating wind turbine. [Coal-mine study](https://www.mdpi.com/2079-9292/14/2/379) · [Nexa operator report, p. 107](https://www.smv.gob.pe/ConsultasP8/temp/Memoria%20Anual%202024%20Nexa%20Peru.pdf) · [Local SCADA thesis](https://www.theseus.fi/bitstreams/585869bd-a8c2-4a1c-83d8-677d42b0f513/download) · [Wind-turbine study](https://doi.org/10.1016/j.egyai.2026.100828)
