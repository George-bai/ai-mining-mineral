## Short summary

Give the on-site agent two narrow tools: **search an approved tag catalogue** and **read a bounded time series for selected tags**. Where the plant supports it, feed an industrial demilitarised zone (DMZ) historian one way from the plant historian. Put the agent’s read service on the copy. Give its connector a dedicated identity that can read only the approved assets and values. Enforce each user’s access at the service, including catalogue searches. This is an article recommendation. The UK NCSC explicitly describes the one-way historian and authenticated API pattern. [NCSC connectivity guidance, Principle 4](https://www.ncsc.gov.uk/collection/operational-technology/secure-connectivity/principle-4)

**Read-only access still leaves three risks.** A shared account can reveal another user’s data. A long or repeated query can overload the historian. An existing tag description or operator note can steer the model’s answer or its next tool call. Enforce permissions and query budgets outside the model. Log who requested which tags and time range, whether the request was allowed, how much came back and how long it took. Keep credentials out of those logs. [MCP tool security](https://modelcontextprotocol.io/specification/2026-07-28/server/tools#security-considerations) · [OWASP on excessive agency](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10/blob/main/2026/final/LLM03_ExcessiveAgency.md)
